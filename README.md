# 운동 기록

4분할 운동 루틴을 세트 단위로 기록하는 모바일 웹앱입니다. 빌드 없이 정적 파일만으로 동작하고, GitHub Pages에서 바로 열립니다.

## 쓰는 법

1. 휴대폰 브라우저에서 Pages 주소를 엽니다.
2. 주소창 메뉴에서 **홈 화면에 추가 / 앱 설치**를 누르면 주소창 없는 앱처럼 열립니다.
3. Day 탭을 골라 세트마다 무게·횟수를 적고 ✓ 를 누르면 90초(또는 60초) 휴식 타이머가 돌고 진동이 옵니다.
4. 끝나면 **오늘 기록 저장** — 히스토리 탭에 쌓이고, **텍스트 복사**로 대화창에 붙여넣을 수 있습니다.

기록은 브라우저 `localStorage`(`sangwoon_workout_v1`)에만 저장됩니다. 서버로 보내지 않습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (탭, 직전 기록, 세트 입력, 타이머, 히스토리) |
| `program.json` | 루틴과 코치 메모. 이 파일만 고쳐 올리면 앱 새로고침 시 바로 반영 |
| `manifest.json` | 홈 화면 앱 설치(PWA) 설정 |
| `sw.js` | 네트워크 우선 캐시 — 온라인이면 항상 최신, 오프라인이면 캐시로 동작 |
| `icon*.png`, `icon.svg` | 앱 아이콘 |

## 루틴 바꾸기

`program.json`의 `program`(요일별 종목)이나 `feedback`(상단 코치 메모)을 수정해 커밋하면 됩니다. `index.html`은 열릴 때마다 `./program.json?v=지금시각`으로 새로 받아오고, 실패하면 내장 기본 루틴으로 돌아갑니다.

`feedback` 예시:

```json
{ "title": "오늘의 코칭 메모", "date": "2026-11-24", "text": "이번 주는 금요일 휴무 — 수요일에 밀기, 목요일은 당기기로 인정." }
```

## 배포

`deploy.sh`가 저장소 확인 → 푸시 → Pages 활성화 → HTTP 200 확인까지 처리합니다.
